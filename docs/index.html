Hermes Usage Center

Hermes Desktop 的模型用量插件。侧栏看自然周期和官方额度；右下角常驻今日 Token，以及 Grok / Codex / Claude 的剩余% 与本周期已用。

GitHub 安装说明

整页看板

右下角状态条

本周期 Token 贴在剩余%旁边，口径是官方重置窗内已用，不是自然周。悬停某一家只看这一家。

官方额度

显示设置

单位可选自动 / 手动，单位制万/亿或 K/M/B。改完立刻作用于本页和右下角。

口径

今日 / 本周 / 本月上海时区自然周期，按会话开始时间归属
近 7 / 30 / 90 天滚动窗口，标签不会写成「本月」
本周期 Token官方重置窗内已用；无官方窗的模型不进这张表
官方额度账户接口或本机额度快照；不用本地 Token 反推会员余量

安装

hermes plugins install chenleshu/hermes-usage-center
hermes plugins enable usage-center

Desktop Settings → Plugins 打开本插件。需要 Hermes ≥ 0.20.4。当前版本 v1.11.0。
